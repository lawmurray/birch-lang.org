# Getting involved

We love to see compelling applications of Birch. These set our direction. If you've been working hard on an interesting problem using Birch, please share it with us in the [discussions](https://github.com/lawmurray/Birch/discussions) section on GitHub. Likewise you can ask (and answer!) questions about Birch there.

There is a list of [startup projects](https://github.com/lawmurray/Birch/labels/startup%20project) that form good entry points for new contributors. Also see [CONTRIBUTING.md](https://github.com/lawmurray/Birch/blob/master/CONTRIBUTING.md) for more on how to contribute (code style, pull requests, etc).
