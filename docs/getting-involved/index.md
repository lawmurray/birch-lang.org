# Getting involved

**Contributions are most welcome!**

We love to see compelling applications of Birch. These set our direction. If you've been working hard on an interesting problem using Birch, your suggestions are valuable to us, so please let us know what you think.

There is a list of [startup projects](https://github.com/lawmurray/Birch/labels/startup%20project) that form good entry points for new contributors.

See [CONTRIBUTING.md](https://github.com/lawmurray/Birch/blob/master/CONTRIBUTING.md) for more on how to contribute.
