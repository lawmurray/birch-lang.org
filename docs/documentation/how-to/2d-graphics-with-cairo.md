# 2d graphics with Cairo

[Birch.Cairo](https://www.github.com/lawmurray/Birch.Cairo) wraps the [Cairo](https://cairographics.org) 2d graphics library for use with Birch. This allows the creation of PNG, SVG and PDF files from Birch code. Basic functionality is available, built around Cairo's C API.

The `draw` program within the [MultiObjectTracking](https://github.com/lawmurray/MultiObjectTracking) package provides an example of use, and the `META.json` file of the same package an example of how to link it into your own package.
