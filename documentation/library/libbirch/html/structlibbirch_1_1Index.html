Detailed Description

template<int64_t offset_value = 0>
struct libbirch::Index< offset_value >

Index, used within a slice to indicate a single element of a dimension.

An Index indicates one element along one dimension of an array. It consists of an Offset only, which may have either a static value (indicated by a template argument giving that value) or a dynamic value (indicated by a template argument of mutable_value and initial value given in the constructor).
