Detailed Description

template<class Head, class ... Tail>
class libbirch::Tie< Head, Tail >

Tie.

A Tie is a tuple of lvalue reference types. It may only be used as a temporary to assign the elements of a Tuple to other variables.

Template Parameters
HeadFirst element type.
TailRemaining element types.

Ties only support lvalue reference types. If there a no lvalue reference types, Tuple may be used instead.
