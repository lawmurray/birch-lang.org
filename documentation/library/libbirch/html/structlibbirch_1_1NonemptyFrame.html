Detailed Description

template<class Head, class Tail>
struct libbirch::NonemptyFrame< Head, Tail >

Nonempty frame.

Template Parameters
TailFrame type.
HeadSpan type.

A frame describes the D dimensions of an array. It consists of a head span describing the first dimension, and a tail tail frame describing the remaining D - 1 dimensions, recursively. The tail frame is EmptyFrame for the last dimension.
