Detailed Description

template<int64_t offset_value = 0, int64_t length_value = mutable_value>
struct libbirch::Range< offset_value, length_value >

Range.

A Range describes the active elements along one dimension of an array. It combines an Offset and Length. Each of these may have either a static value (indicated by a template parameter giving that value) or a dynamic value (indicated by a template parameter of mutable_value and initial value given in the constructor).
