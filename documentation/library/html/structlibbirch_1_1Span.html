Detailed Description

template<int64_t length_value = mutable_value, int64_t stride_value = mutable_value>
struct libbirch::Span< length_value, stride_value >

Span.

A Span describes one dimension of an array. It combines a Length and Stride to indicate the size of the dimension. Each of these may have a static value (indicated by a template parameter giving that value) or a dynamic value (indicated by a template parameter of mutable_value and initial value given in the constructor).
