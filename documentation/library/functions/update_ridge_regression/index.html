    update_ridge_regression

    function update_ridge_regression(x:Real[_], N:Real[_,_], Λ:LLT, α:Real, γ:Real[_], u:Real[_]) -> (Real[_,_], LLT, Real, Real[_])

    Update parameters for a linear-Gaussian ridge regression.

    • x: The variate.
    • N: Prior precision times mean for weights, where each column represents the mean of the weight for a separate output.
    • Λ: Common prior precision.
    • α: Common prior weight and likelihood covariance shape.
    • β: Prior covariance scale accumulators.
    • u: Input.

    Returns: the posterior hyperparameters N', Λ', γ', and β'.
