Detailed Description

template<class Head, class Tail>
struct libbirch::NonemptyView< Head, Tail >

Nonempty view.

Template Parameters
HeadRange or Index type.
TailView type.

A view describes the active elements over D dimensions of an array. It consists of a head range or index for the first dimension, and a tail view for the remaining D - 1 dimensions, recursively. The tail view is EmptyView for the last dimension.
