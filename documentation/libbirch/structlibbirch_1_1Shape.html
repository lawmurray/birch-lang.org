Detailed Description

template<class Head, class Tail>
struct libbirch::Shape< Head, Tail >

Shape of an array.

Template Parameters
HeadDimension type.
TailShape type.

A shape describes the D dimensions of an array. It consists of a head dimension describing the first dimension, and a tail tail shape describing the remaining D - 1 dimensions, recursively. The tail shape is EmptyShape for the last dimension.
