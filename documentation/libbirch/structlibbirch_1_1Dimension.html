Detailed Description

template<int64_t length_value = mutable_value, int64_t stride_value = mutable_value>
struct libbirch::Dimension< length_value, stride_value >

Dimension of an array.

Describes one dimension of an array. It combines a Length and Stride to indicate the size of the dimension. Each of these may have a static value (indicated by a template argument giving that value) or a dynamic value (indicated by a template argument of mutable_value and initial value given in the constructor).
