Detailed Description

template<class Head, class Tail>
struct libbirch::Slice< Head, Tail >

Slice into an array.

Template Parameters
HeadRange or Index type.
TailSlice type.

A slice describes the active elements over D dimensions of an array. It consists of a head Range or Index for the first dimension, and a tail slice for the remaining D - 1 dimensions, recursively. The tail slice is EmptySlice for the last dimension.
