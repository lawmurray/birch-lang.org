template<class Head, class ... Tail>
class libbirch::Tuple< Head, Tail >

Tuple.

Template Parameters
HeadFirst element type.
TailRemaining element types.

Tuples do not support lvalue reference types. If all types are lvalue reference types, Tie may be used instead.
